EMR 시스템 마비
전자의무기록 접근 불가 → 환자 정보 조회 차단
↓
⛔
진료 중단
응급실 포함 전면 진료 중단 → 3가지 리스크 분기
분기 1
응급환자 피해
시나리오:
응급실 환자 치료 지연 → 의료사고 발생 → 환자 가족이 의료과실로 손해배상 청구

법적 쟁점:
"EMR 마비는 예견 가능한 리스크였으므로 병원의 과실"
💰 손해배상: KRW 5억 원
⏱️ 소송 기간: 2년
📋 필요 담보: PI (의료과실 책임)
분기 2
환자 정보 유출
시나리오:
랜섬웨어 공격 과정에서 환자 개인정보 10만 건 유출 → PIPA 위반 조사 개시

규제 리스크:
"개인정보보호법 위반으로 과징금 부과"
💰 과징금: KRW 3억 원
📋 조사 비용: KRW 5천만 원
🛡️ 필요 담보: 규제 대응 (PIPA)
분기 3
영업 중단 손실
시나리오:
EMR 복구 기간 14일 → 전면 휴진 → 일 평균 매출 KRW 2천만 원 손실

경제적 리스크:
"직접 매출 손실 + 환자 이탈 + 평판 훼손"
💰 매출 손실: KRW 2.8억 원
📉 평판 훼손: 환자 20% 이탈
💼 필요 담보: BI (영업중단 손해)
📅 EMR 마비 사고 타임라인 (14일)
Day 0 (00:00)
랜섬웨어 감염 탐지 → 즉시 서버 격리 → EMR 시스템 다운
Day 0 (02:00)
응급실 환자 이송 불가 → 의료사고 발생 (분기 1 시작)
Day 1
전면 휴진 공지 → 일 평균 KRW 2천만 원 손실 시작 (분기 3)
Day 3
PIPA 조사 개시 → 환자 정보 10만 건 유출 확인 (분기 2)
Day 14
EMR 복구 완료 → 진료 재개 (총 손실 KRW 10.8억)

💡 핵심 인사이트

의료 협회군의 EMR 마비는 3가지 연쇄 리스크(PI/규제/BI)로 확산되며, 단일 보험으로는 커버 불가능합니다. 록톤 듀얼 상품은 원인(사이버)부터 결과(PI/BI/규제)까지 통합 보장하여 의료 기관의 생명줄인 EMR 시스템을 완전히 보호합니다.
